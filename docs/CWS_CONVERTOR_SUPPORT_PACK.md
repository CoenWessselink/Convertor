# CWS Convertor support pack

Collect the following without changing production data:

- application version and Project Model version;
- source file SHA-256 values, without confidential contents when prohibited;
- `.cwscproj` project and relevant validation report;
- `validation/phases` checklist/evidence files;
- runtime self-test and GUI-smoke JSON;
- release manifest and `SHA256SUMS.txt`;
- exact error namespace/code and reproduction steps;
- Windows version, DPI, GPU/driver and available RAM.

Never include machine authorization keys or claim machine qualification from a software support pack.
