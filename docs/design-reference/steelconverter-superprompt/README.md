## How to use these images

Use every image as input when designing the relevant surface. The references
collectively describe product flow, navigation, viewer density, measurement
tools, status handling and drawing families. No single image defines the whole
application.

The explicit superprompt and product foundation are authoritative when a visual
concept conflicts with them. In particular, the nine textual main-menu areas
are leading, `Tekeningen` remains a separate main area, and generated dimensions
or counts are never treated as validated expectations.
