## Regel

De PNG's zijn visuele ontwerpinput. Ze mogen desgewenst in ontwikkelaarsdocumentatie of een helpgalerij worden meegeleverd, maar mogen nooit worden gebruikt als achtergrond waarop onzichtbare klikzones worden gelegd en nooit als vervanging van live gerenderde software.
