# CWS Convertor PDF UI — Codex-integratiepakket V3

Dit pakket bevat één volledige Codex-startprompt en drie visuele referenties voor de integratie van de interactieve PDF-maatvoering in het totale CWS Convertor-pakket.

## Gebruik

1. Pak de ZIP uit.
2. Voeg de volledige map als bijlage toe aan een Codex-taak of plaats haar in de repository onder bijvoorbeeld `docs/design/pdf-ui-v3/`.
3. Laat Codex eerst `CODEX_INTEGRATIEPROMPT_PDF_UI_V3.md` lezen.
4. Geef Codex toegang tot de actuele repository en GitHub Actions.
5. Laat Codex alle afbeeldingen behandelen als ontwerpdoel en nooit als technisch testbewijs.

## Belangrijk

De referentiebeelden bevatten voorbeeldprojecten en voorbeeldwaarden. Codex moet de informatiehiërarchie en bediening integreren, maar geen fictieve klant-, project-, datum- of maatdata hardcoden. De uiteindelijke toepassing moet native PySide6-bediening gebruiken.

Echt bewijs moet opnieuw uit de gebouwde bronapp, Windows EXE, portable runtime en geïnstalleerde applicatie worden gegenereerd.
