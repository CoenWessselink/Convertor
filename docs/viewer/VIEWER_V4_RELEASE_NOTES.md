# CWS Viewer V4 — release notes

## Identiteit

- Product: **CWS Convertor**
- Module: **CWS Viewer**
- Viewer package: `0.5.0-dev0`
- Fase: V4 professionele bediening, workspace en Accuracy/Debug

## Nieuw

- professionele camera-, render-, achtergrond- en kleurbediening;
- hide/show/isolate/ghost/transparency;
- viewpoints en visibility sets;
- atomische, checksum-geverifieerde `.cwsview.json`;
- veilige stable-ID subsetrestore bij revisies;
- Accuracy/Debug Mode;
- deterministische exacte-veldzoekranking;
- uitgebreidere Qt-projectviewer;
- Windows source/packaged/portable gateconfiguratie;
- SteelConverter-superprompt en conceptbeelden als vastgezette requirementsreferentie.

## Niet geleverd

- true hidden-line removal;
- sections/measurements;
- exact Part Workbench BREP-picking;
- productie-exportvrijgave;
- Windows EXE/portable bewijs in deze omgeving.
